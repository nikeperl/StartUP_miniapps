# Задания по дисциплине «Разработка программ на базе ИИ»

Репозиторий содержит три самостоятельных учебных модуля. Каждый модуль лежит в отдельной папке, имеет собственный `requirements.txt`, `README.md` и запускается через `script.py`.

## Структура

| Папка | Назначение |
| --- | --- |
| `GenAI-1-40` | Построение эмбеддингов документов (`txt`, `pdf`, `docx`) и вычисление косинусного сходства между ними. |
| `GenAI-2-23` | Генерация пар вопрос-ответ по входному текстовому файлу. |
| `GenAI-3-23` | Генерация пар вопрос-ответ по заданной теме или короткому тексту с сохранением результата в CSV. |

## Общие требования

- Python 3.8+
- Доступ к интернету при первом запуске моделей Hugging Face / Sentence Transformers
- Желательно использовать виртуальное окружение

Пример подготовки окружения:

```bash
python -m venv .venv
source .venv/bin/activate
```

Для Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

## Установка и запуск

Зависимости устанавливаются отдельно для нужного модуля:

```bash
cd GenAI-1-40
pip install -r requirements.txt
python script.py --help
```

Аналогично можно перейти в `GenAI-2-23` или `GenAI-3-23` и выполнить те же команды.

## Быстрые примеры

Создать эмбеддинг документа:

```bash
cd GenAI-1-40
python script.py encode --file data/ubuntu.txt
```

Посчитать сходство двух эмбеддингов:

```bash
python script.py similarity --file1 data/doc1_emb.npy --file2 data/doc2_emb.npy
```

Сгенерировать вопросы по текстовому файлу:

```bash
cd GenAI-2-23
python script.py data/text.txt --num_questions 5
```

Сгенерировать вопросы по теме:

```bash
cd GenAI-3-23
python script.py "Artificial Intelligence and its applications" --num_questions 5
```

## Примечания

- Модели загружаются при первом запуске и могут занимать заметное место на диске.
- Для лучшего качества генерации во втором и третьем модуле рекомендуется использовать английский текст.
- При отсутствии GPU скрипты работают на CPU, но генерация может быть медленной.
