# Эмбеддинги документов и косинусное сходство

Модуль строит эмбеддинг документа с помощью `sentence-transformers` и позволяет сравнивать два сохранённых эмбеддинга через косинусное сходство.

## Возможности

- Чтение документов в форматах `txt`, `pdf`, `docx`.
- Разбиение большого текста на фрагменты.
- Сохранение эмбеддинга в файл `.npy`.
- Вычисление косинусного сходства между двумя эмбеддингами.

## Установка

Все команды выполняются из каталога `GenAI-1-40`:

```bash
pip install -r requirements.txt
```

## Использование

Создать эмбеддинг:

```bash
python script.py encode --file data/ubuntu.txt
```

После выполнения рядом с исходным документом появится файл вида `data/ubuntu_emb.npy`.

Сравнить два эмбеддинга:

```bash
python script.py similarity --file1 data/doc1_emb.npy --file2 data/doc2_emb.npy
```

Пример вывода:

```text
Косинусное сходство: 0.8732
```

## Аргументы

### `encode`

| Аргумент | Описание |
| --- | --- |
| `--file` | Путь к документу в формате `txt`, `pdf` или `docx`. |

### `similarity`

| Аргумент | Описание |
| --- | --- |
| `--file1` | Путь к первому `.npy` файлу с эмбеддингом. |
| `--file2` | Путь ко второму `.npy` файлу с эмбеддингом. |

## Примечания

- При первом запуске модель `all-MiniLM-L6-v2` будет загружена автоматически.
- Если из документа не удалось извлечь текст, эмбеддинг не создаётся.
- Для корректного сравнения оба эмбеддинга должны иметь одинаковую размерность.
