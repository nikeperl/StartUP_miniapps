# Генератор вопросов по тексту

Модуль генерирует пары вопрос-ответ по содержимому текстового файла. Для генерации вопросов используется `google/flan-t5-large`, для поиска ответа в выбранном фрагменте текста используется `distilbert-base-uncased-distilled-squad`.

## Возможности

- Чтение входного `.txt` файла.
- Очистка текста и разбиение на предложения.
- Генерация нескольких пар вопрос-ответ.
- Сохранение результата в текстовый файл.
- Использование GPU при наличии.

## Установка

Все команды выполняются из каталога `GenAI-2-23`:

```bash
pip install -r requirements.txt
```

## Использование

```bash
python script.py data/text.txt --output_file data/output.txt --num_questions 5
```

Если `--output_file` не указан, результат будет сохранён рядом с исходным файлом в формате `{input_file}_Q&A.txt`.

## Аргументы

| Аргумент | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `input_file` | `str` | требуется | Путь к входному текстовому файлу. |
| `--output_file` | `str` | `{input_file}_Q&A.txt` | Путь к выходному файлу. |
| `--num_questions` | `int` | `3` | Количество генерируемых пар вопрос-ответ. |
| `--max_tokens` | `int` | `256` | Максимальное количество токенов в сгенерированном вопросе. |

## Формат результата

```text
S: Artificial Intelligence is used in healthcare, finance, and education.
Q: Where is Artificial Intelligence used?
A: healthcare, finance, and education
--------------------------------------------------
```

## Примечания

- Рекомендуется использовать тексты на английском языке: выбранные модели лучше работают с английским.
- При первом запуске модели будут загружены автоматически.
- На CPU генерация может выполняться медленно.
